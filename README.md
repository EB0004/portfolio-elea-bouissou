# Portfolio — Eléa Bouissou

Version exportée du portfolio web, prête à être remise à un développeur ou
hébergée sous un nom de domaine personnel.

## Contenu

- code du portfolio dans `app/`
- photographies et ressources dans `public/images/`
- animations et galerie interactive « Coulisses »
- mise en page responsive

## Lancer le portfolio

Prérequis : Node.js 22.13 ou version ultérieure.

```bash
npm ci
npm run dev
```

## Construire la version de production

```bash
npm run build
```

Cette archive ne contient ni historique Git, ni fichiers d’hébergement liés à
la plateforme d’origine. Elle peut donc servir de base à une publication sous
un domaine tel que `eleabouissou.com`.
